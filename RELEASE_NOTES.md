# 🚀 Release Notes: v1.0.0 - OMEGA POINT

Welcome to the initial stable release of **SOFTCURSE File Reader**. This version marks the transition from a simple utility to a fully-featured, cyberpunk-infused data visualization portal.

---

### 🎨 Visual & UI Enhancements
- **Cyber Reticle:** Replacing the standard mouse with the high-precision "Cyber S" cursor.
- **Premium Aesthetics:** Void-black glassmorphism with grid backgrounds and neon cyan highlights.
- **Tactical Typography:** High-visibility 16px fonts with support for monospace icons and emojis.

### 📜 Technical Capabilities
- **Universal Rendering:** Native support for ANSI colors and `CP437` block characters.
- **Safe Loader:** Automated 50MB file overflow protection.
- **Format Agnostic:** Reads source code, logs, and legacy BBS art with zero corruption.

### 🏗️ Build & Deployment
- Standalone Windows executable support via PyInstaller.
- Integrated Inno Setup installer script with global file associations.
